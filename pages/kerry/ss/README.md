# 海空战 · SEA STRIKE

一个用**纯 HTML + WebGL 手写**的舰载机空战游戏。所有 3D 模型（战机 / 核潜艇母 / 驱逐舰 / 导弹 / 炸弹 / 岛屿 / 云）都是**代码实时生成的**，没有任何外部模型、贴图或第三方库——双击 `index.html` 即可玩。

## 运行

直接双击打开 `index.html`（Chrome / Edge / Safari 均可，需要 WebGL）。
或者起个静态服务器（iPad 访问必须用这种方式）：

```bash
./serve.sh          # 默认 8770 端口，会打印 iPad 可访问的地址
./serve.sh 8790     # 端口冲突时换端口
```

## 部署

这是一个**纯静态站点**：没有构建步骤、没有依赖、没有后端，整个目录就是产物
（`index.html` + `js/`）。任何静态托管都能直接用。

**① 局域网（最快，iPad 现在就能玩）**

```bash
cd sea-strike && python3 -m http.server 8770 --bind 0.0.0.0
# iPad Safari 打开 http://<电脑局域网IP>:8770
```

**② Netlify Drop（不用装任何工具，30 秒上公网 HTTPS）**
打开 <https://app.netlify.com/drop> → 把 `sea-strike` 文件夹整个拖进去 →
立刻拿到 `https://xxx.netlify.app`，iPad 直接打开就能玩。

**③ GitHub Pages（免费、长期稳定）**
本机已装 git（未装 gh / npm，需要你在浏览器里手动建一次空仓库）：

```bash
cd sea-strike
git init && git add . && git commit -m "SEA STRIKE"
# 到 github.com 新建空仓库（不要勾 README），然后：
git remote add origin git@github.com:<你的用户名>/<仓库名>.git
git push -u origin main
# 仓库 Settings → Pages → Source 选 main 分支 / root → 等 1 分钟
```

仓库里已经放了 `.nojekyll`，避免 Pages 的 Jekyll 处理。Cloudflare Pages / Vercel
同样是拖拽或上传流程。

## iPad / 手机（触屏）

**可以直接在 iPad 上玩**，用 Safari 打开本页面即可（横屏体验最佳）。

- **左半屏任意位置按下 → 出现虚拟摇杆**：上下推杆俯仰、左右推杆滚转（模拟量，不是死板的按键）。
- **右侧竖条**：拖动调油门（推到底 + 拉摇杆 = 甲板弹射起飞）。
- **右下角按钮**：锁定（按住锁定、松开发射）/ 机炮（按住）/ 起落架 / 干扰弹 / 炸弹 / 视角。
- 左上角 `❚❚` 暂停。
- 推荐 **分享 → 添加到主屏幕**，这样会全屏运行、没有地址栏，还能隐藏 Safari 的工具栏。

触屏会自动开启；桌面上不会出现。也可以在主菜单手动切换「📱 触屏模式」，或用 `index.html?touch=1` 强制开启（方便在电脑上预览 iPad 布局）。

iPad 相关的适配细节：视口锁定 + 安全区留白、禁止双击缩放/页面橡皮筋、触摸即解锁音频、后台自动暂停；
移动端自动切换画质档（渲染分辨率 0.72×、DPR 上限 1.75、海面网格降密、关闭阴影），并按实测帧率**动态升降渲染分辨率**（掉帧自动降、流畅自动升），HUD 也会重排避开拇指区。

## 任务流程

1. **弹射起飞**：战机停在航母艉部甲板，加满油门（Shift）后按 `空格` 触发弹射器，约 2.5 秒加速到 70 m/s，自动带杆离舰。
2. **空战拦截**：爬升到 2000 m 以上，依次迎击 3 个波次共 9 架敌机。
3. **返航着舰**：肃清空域后返航，放下起落架，沿 3.4° 下滑道对正中线，以 45–110 m/s 着舰。

胜利 = 击落全部敌机 **且** 安全返航着舰。

## 飞行模型

- 升力系数按迎角线性增长、到 `ClMax=1.55` 后缓慢衰减（失速后仍有 45% 升力，不会"一拉就掉"）。
- 阻力含寄生阻力 + 诱导阻力 + 起落架/襟翼/减速板附加阻力，低空有地面效应。
- 飞控律模拟（FLAT-B）：迎角超过 ~22° 后操纵权限衰减，超过 ~24° 自动推杆，避免一拉到底翻筋斗。
- **进近模式**：起落架放下、低空、接近母舰时，松杆状态下自动跟随 3.4° 下滑道并保持 7° 迎角；手动操纵随时覆盖。
- 失速速度约 66 m/s（238 km/h），满油加力极速约 1400 km/h。
- 惯性导航：四元数积分（机体系角速度）+ 迎角/侧滑力模型。

## 文件结构

```
index.html        页面、菜单、样式
js/math.js        vec3 / mat4 / 四元数（旋转矩阵与积分均已校验）
js/meshbuilder.js 低多边形网格构造器（平面着色）
js/models.js      全部程序化模型：fighter / carrier / destroyer / missile / bomb / island / cloud / buoy
js/gl.js          WebGL 渲染器：海面（极坐标网格 + 顶点波动 + 细浪法线 + 阳光反射）、天空、粒子、线段
js/effects.js     粒子系统：爆炸、尾焰、烟、翼尖涡流、尾迹、水花、尾流
js/entities.js    飞行力学、舰船运动、导弹制导、炸弹、干扰弹、敌机 AI
js/hud.js         平显：航向带、速度/高度带、姿态仪、雷达、锁定框、进近指示、告警
js/touch.js       iPad/触屏：浮动虚拟摇杆、油门杆、功能按钮
js/audio.js       WebAudio 合成音效（发动机/风噪/锁定音/导弹/爆炸…），无音频文件
js/game.js        主循环、状态机、任务流程、输入、渲染调度、画质自适应
```

## 调试入口

浏览器控制台里可用：`G`（游戏状态）、`G.keys`（直接改按键状态）、
`G._start()`（直接开局）、`G._log('...')`、`G._render()`、
`TouchUI.enable(true)`（强制开触屏）、`GL.setRenderScale(0.8)`（锁渲染分辨率）。页面标题会在运行期报错时变成 `⚠ 错误信息`，错误也会收集在 `window.__errors`。
